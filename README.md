## Русский

Всем привет! **Scamlock** добавляет интерактивную рулетку предметов и режим случайного драфта прямо в магазин Deadlock.

Если надоело каждую игру покупать одни и те же шаблонные билды из меты, мод превращает каждый поход на базу в азартную игру. Нажимаешь `B`, крутишь барабан — и колесо выбирает твой следующий предмет. Выпало что-то годное — покупаешь, выпала полная дичь — жмешь «Скип» или пытаешься затащить на странном затаре. 

Отлично заходит для заруб с друзьями в кастомных лобби, стримов и одиночных челленджей.

Также есть **режим Драфта**, если хочется сгенерировать случайный билд на всю катку и сразу отправить его в быструю покупку. А если посреди игры нужно срочно взять конкретный обычный предмет, в стандартный магазин Deadlock всегда можно вернуться в один клик.

### Установка
- **Через Deadlock Mod Manager (самый простой способ)**: просто перетащите архив `Scamlock.zip` в окно менеджера, поставьте галочку и запускайте игру.
- **Вручную**: распакуйте `scamlock.vpk` из архива `Scamlock.zip`. Движок игры читает только файлы вида `pakXX_dir.vpk`, поэтому переименуйте файл в `pak01_dir.vpk` (или в `pak02_dir.vpk`, если у вас уже стоит другой мод, например UMM) и закиньте в папку `Deadlock/game/citadel/addons/`.

### Управление
- `B` — Открыть магазин / Scamlock
- Кнопки в меню: Крутить барабан, Скип, Драфт, Магазин, переключатель RU / EN

### Настройки через Universal Mod Manager (UMM)
Если у вас установлен **Universal Mod Manager**, в игровом меню (Esc -> Моды) доступны настройки:
- Соотношение сторон (16:9, 16:10, 4:3)
- Масштаб интерфейса
- Стартовая вкладка при открытии (Рулетка или Драфт)
- Звуки вращения колеса

*(Наличие Universal Mod Manager не обязательно — Scamlock полностью работает и без него).*

## English

Hey everyone! **Scamlock** adds an interactive item roulette wheel and random draft mode right into the Deadlock shop.

If you're tired of buying the same cookie-cutter meta builds every game, this mod turns every visit to the shop into a gamble. Press `B`, spin the wheel, and let RNG decide your next purchase! Got a game-winning item? Buy it. Got something cursed? Hit Skip or try to carry with it anyway. 

It's super fun for 6v6 custom lobbies with friends, solo roulette challenges, and streaming.

There's also a **Draft mode** if you want to roll a randomized build before the horn sounds and queue items straight into your Quickbuy. And whenever you need to check standard items, you can hop back to the vanilla shop anytime with a single click.

### Installation
- **Deadlock Mod Manager (Easiest)**: Drag and drop `Scamlock.zip` into the manager, enable the mod, and launch the game.
- **Manual Install**: Extract `scamlock.vpk` from `Scamlock.zip`. Source 2 requires mods to use the `pakXX_dir.vpk` format, so rename the file to `pak01_dir.vpk` (or `pak02_dir.vpk` if you already use another mod like UMM) and place it into `Deadlock/game/citadel/addons/`.

### Controls
- `B` — Open Shop / Scamlock
- In-game buttons: Spin The Wheel, Skip, Draft, Vanilla Shop, RU / EN language toggle

### Universal Mod Manager (UMM) Settings
If you have **Universal Mod Manager** installed, in-game options are available under Esc -> Mods:
- Aspect Ratio (16:9, 16:10, 4:3)
- UI Scale
- Default starting tab (Roulette or Draft)
- Wheel sound effects

*(Universal Mod Manager is optional — Scamlock runs standalone out of the box).*
